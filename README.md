# 早该看看了 - 本地视频管理工具

这是一个基于Electron的本地视频管理桌面应用程序，可以帮助您管理和组织本地视频文件。

## 功能特点

- 导入并管理本地视频文件
- 表格视图和画廊视图切换
- 视频文件筛选和搜索
- 批量操作功能
- 视频播放记录跟踪

## 安装与运行

### 开发环境

1. 确保您已安装 [Node.js](https://nodejs.org/) (推荐v16或更高版本)

2. 克隆或下载本项目

3. 安装依赖
   ```
   cd V3
   npm install
   ```

4. 启动应用
   ```
   npm start
   ```

### 构建可执行文件

要构建Windows可执行文件，请运行：

```
npm run build
```

构建完成后，可执行文件将位于`dist`目录中。

## 使用说明

1. **导入视频**：点击左上角的"导入视频"按钮，选择本地视频文件。

2. **切换视图**：使用右上角的视图切换按钮在表格视图和画廊视图之间切换。

3. **搜索视频**：使用顶部的搜索框搜索视频文件。

4. **筛选视频**：点击筛选按钮设置筛选条件。

5. **批量操作**：选择多个视频后，可以进行批量移动、隐藏或移除操作。

6. **播放视频**：点击视频卡片或表格中的播放按钮，使用系统默认播放器播放视频。
