## 📖 项目简介

"早该看看了"是一款基于 Electron 开发的本地视频管理桌面应用程序，专为需要管理大量本地视频文件的用户设计。它提供了直观的界面和强大的功能，帮助您轻松整理、分类、搜索和观看本地视频收藏。

### 🎯 适用人群
- **影视收藏爱好者** - 管理电影、剧集等视频收藏
- **学习者** - 整理教学视频和学习资料
- **内容创作者** - 管理视频素材和作品
- **专业收藏者** - 需要精细分类和标记的用户

## ✨ 核心功能

### 📁 视频管理
- **智能导入** - 支持单文件和文件夹批量导入
- **自动信息提取** - 自动获取视频分辨率、时长、文件大小等信息
- **缩略图生成** - 自动生成视频预览缩略图（30%位置帧）
- **重复检测** - 智能识别和清理重复视频条目

### 🔍 搜索与筛选
- **全文搜索** - 支持文件名、标题、标签、演员、备注、路径搜索
- **高级筛选** - 按分辨率、评分、观看次数、标签等条件筛选
- **智能排序** - 支持多字段排序和自定义排序规则

### 📊 视图模式
- **表格视图** - 详细信息一览无余，支持列自定义和排序
- **画廊视图** - 缩略图网格展示，视觉效果更佳
- **详情抽屉** - 完整的视频信息查看和编辑界面

### 🏷️ 元数据管理
- **丰富的标签系统** - 支持自定义标签、演员、评分等信息
- **观看记录** - 自动记录观看次数和最后观看时间
- **批量编辑** - 支持多选批量修改视频信息

### 🛠️ 高级功能
- **视频压缩** - 内置 FFmpeg，支持高效感知无损和完全无损压缩
- **GPU 加速** - 支持 NVIDIA GPU 硬件加速压缩
- **文件迁移** - 批量移动视频文件并自动更新路径
- **数据备份** - 支持数据导出导入，便于迁移和备份

### 🎮 便捷操作
- **快速播放** - 一键使用系统默认播放器打开视频
- **文件夹访问** - 快速定位到视频所在文件夹
- **批量操作** - 支持多选进行批量移动、压缩、删除等操作
- **键盘快捷键** - 提供常用操作的快捷键支持

## 💻 系统要求

### 支持的操作系统
- **Windows 10** 或更高版本（推荐）
- **Windows 8.1**（基本支持）

### 硬件要求
- **处理器**: Intel Core i3 或 AMD 同等级别以上
- **内存**: 4GB RAM（推荐 8GB 或更多）
- **存储空间**: 500MB 可用磁盘空间
- **显卡**: 
  - 基本功能：集成显卡即可
  - GPU 加速压缩：NVIDIA GTX 1050 或更高（支持 NVENC）

### 软件依赖
- **Node.js**: 16.0 或更高版本（仅开发环境需要）
- **FFmpeg**: 内置，无需额外安装

## 🚀 快速开始

### 首次使用
1. **启动应用** - 双击桌面图标或从开始菜单启动
2. **导入视频** - 点击"导入视频"或"导入文件夹"按钮
3. **选择文件** - 选择要管理的视频文件或包含视频的文件夹
4. **等待处理** - 应用会自动分析视频并生成缩略图
5. **开始管理** - 导入完成后即可开始管理您的视频库

### 基本操作
- **播放视频**: 双击视频卡片或表格行
- **查看详情**: 右键点击视频选择"查看详情"
- **编辑信息**: 在详情面板中点击"编辑"按钮
- **搜索视频**: 在顶部搜索框输入关键词
- **切换视图**: 点击右上角的视图切换按钮
- **批量操作**: 选中多个视频后使用底部操作栏

### 高级功能使用

#### 视频压缩
1. 选择要压缩的视频
2. 点击"压缩"按钮
3. 选择压缩模式（高效感知无损/完全无损）
4. 配置选项（GPU加速、自动标签等）
5. 开始压缩并监控进度

#### 文件迁移
1. 选择要迁移的视频
2. 点击"迁移"按钮
3. 选择目标文件夹
4. 确认迁移，应用会自动更新文件路径

## 📋 功能详解

### 视频信息字段
- **基础信息**: 文件名、文件路径、文件大小、创建时间
- **视频属性**: 分辨率、时长、编码格式
- **自定义信息**: 标题、标签、演员、评分、备注、上映时间
- **统计信息**: 观看次数、最后观看时间、导入时间

### 压缩功能说明
- **高效感知无损**: 使用 H.265 编码，在保持视觉质量的同时显著减小文件大小
- **完全无损**: 智能选择最优策略，确保视频质量完全不变
- **GPU 加速**: 利用 NVIDIA 显卡硬件加速，大幅提升压缩速度
- **自动标签**: 压缩完成后自动为视频添加相应标签

### 数据存储
- **数据库**: 使用 NeDB 本地数据库存储视频信息
- **缩略图**: 存储在应用数据目录的 thumbnails 文件夹
- **配置文件**: 用户设置和偏好保存在本地配置文件中
- **数据位置**: 
  - 开发环境: 项目目录下的 `userdata` 文件夹
  - 生产环境: 应用安装目录下的 `userdata` 文件夹

## 🐛 常见问题

### Q: 应用启动失败或白屏
A: 请确保系统满足最低要求，尝试以管理员身份运行，或重新安装应用。

### Q: 视频导入失败
A: 检查视频文件是否损坏，确保文件路径不包含特殊字符，尝试重新导入。

### Q: 缩略图生成失败
A: 确保 FFmpeg 组件正常工作，检查视频文件格式是否支持。

### Q: GPU 加速不可用
A: 确保安装了最新的 NVIDIA 显卡驱动，检查显卡是否支持 NVENC 编码。

### Q: 压缩后文件变大
A: 某些已经高度压缩的视频可能无法进一步压缩，这是正常现象。
