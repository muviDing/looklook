# 早该看看了 - 项目架构设计文档

## 1. 架构概述

"早该看看了"是一款基于Electron的本地视频管理工具，采用前后端分离的桌面应用架构。本文档描述了项目的总体架构设计，包括技术选型、架构模式、模块划分和数据流设计。

```

+-----------------------+
```

### 1.2 技术栈

- **应用框架**：Electron v28.1.0
- **UI构建**：HTML5 + CSS3 + JavaScript (ES6)
- **样式框架**：Tailwind CSS v2.2.19
- **图标库**：Font Awesome v6.0.0
- **数据库**：NeDB（嵌入式NoSQL数据库）
- **视频处理**：FFmpeg (via fluent-ffmpeg)
- **构建工具**：electron-builder v24.9.1

### 1.3 架构特点

- **模块化设计**：UI和业务逻辑按功能区域模块化，便于维护
- **区域分隔**：界面按功能区域清晰划分，提高开发效率
- **数据隔离**：使用Electron的上下文隔离机制，提高安全性
- **IPC通信**：通过安全的IPC机制实现主进程和渲染进程通信
- **嵌入式存储**：使用NeDB实现轻量级数据持久化
- **缩略图生成**：集成FFmpeg实现视频缩略图自动生成

## 3. 技术实现细节

### 3.1 IPC通信机制

Electron应用中，主进程和渲染进程之间通过IPC(进程间通信)机制进行通信。为了确保安全性，本项目采用上下文隔离方式，并通过preload.js预加载脚本暴露有限的API：

```javascript
// preload.js
const { contextBridge, ipcRenderer } = require('electron');

contextBridge.exposeInMainWorld('electronAPI', {
  // 窗口控制
  minimizeWindow: () => ipcRenderer.send('window-minimize'),
  maximizeWindow: () => ipcRenderer.send('window-maximize'),
  closeWindow: () => ipcRenderer.send('window-close'),
  
  // 视频管理
  importVideos: () => ipcRenderer.invoke('import-videos'),
  getVideos: () => ipcRenderer.invoke('get-videos'),
  // 其他API...
});
```

主进程中注册对应的处理函数：

```javascript
// main.js (主进程)
function registerIpcHandlers() {
  // 窗口控制
  ipcMain.on('window-minimize', () => {
    if (mainWindow) mainWindow.minimize();
  });
  
  // 视频管理
  ipcMain.handle('get-videos', () => {
    return db.getVideoCache();
  });
  
  ipcMain.handle('import-videos', async () => {
    // 实现视频导入逻辑...
  });
  
  // 其他处理函数...
}
```

### 3.3 视频缩略图生成

使用FFmpeg生成视频缩略图：

```javascript
// main.js
function generateThumbnail(videoPath, outputPath) {
  return new Promise((resolve, reject) => {
    // 获取视频时长
    ffmpeg.ffprobe(videoPath, (err, metadata) => {
      if (err) {
        reject(err);
        return;
      }
      
      // 获取视频时长（秒）
      const duration = metadata.format.duration;
      
      // 在视频30%位置截取一帧作为缩略图
      const screenshotTime = duration * 0.3;
      
      ffmpeg(videoPath)
        .screenshots({
          timestamps: [screenshotTime],
          filename: path.basename(outputPath),
          folder: path.dirname(outputPath),
          size: '320x180' // 16:9 缩略图尺寸
        })
        .on('end', () => {
          resolve(outputPath);
        })
        .on('error', (err) => {
          reject(err);
        });
    });
  });
}
```

### 4.3 关键数据流程

#### 4.3.1 导入视频流程

1. 用户点击"导入视频"按钮
2. 渲染进程通过IPC请求主进程打开文件选择对话框
3. 用户选择视频文件
4. 主进程处理选中的文件：
   - 检查是否重复
   - 读取文件基本信息
   - 使用FFmpeg生成缩略图
   - 创建视频数据对象并保存到数据库
5. 主进程返回处理结果到渲染进程
6. 渲染进程更新视频数据和UI显示

#### 4.3.2 播放视频流程

1. 用户点击视频卡片或播放按钮
2. 渲染进程通过IPC请求主进程打开视频
3. 主进程使用系统默认播放器打开视频文件
4. 主进程更新视频观看记录
5. 数据库保存更新后的视频信息
6. 下次打开应用时，展示更新后的观看记录

## 5. 安全设计

### 5.1 上下文隔离

使用Electron的上下文隔离机制，防止渲染进程直接访问Node.js API：

```javascript
// 创建浏览器窗口
mainWindow = new BrowserWindow({
  width: 1200,
  height: 800,
  webPreferences: {
    preload: path.join(__dirname, 'preload.js'),
    contextIsolation: true,   // 启用上下文隔离
    nodeIntegration: false    // 禁用Node集成
  }
});
```

### 5.2 最小权限原则

通过preload.js仅暴露必要的API给渲染进程，限制渲染进程的权限：

```javascript
// 仅暴露必要的API
contextBridge.exposeInMainWorld('electronAPI', {
  // 只提供有限的功能接口
  // ...
});
```

### 5.3 输入验证

## 7. 性能优化

### 7.1 数据缓存

采用内存缓存减少数据库访问：

```javascript
// 视频数据缓存
let videoCache = [];

// 加载所有视频数据到缓存
function loadAllVideos() {
  return new Promise((resolve, reject) => {
    db.find({}).sort({ updatedAt: -1 }).exec((err, docs) => {
      if (err) {
        reject(err);
        return;
      }
      
      videoCache = docs;
      resolve(docs);
    });
  });
}
```

### 7.2 延迟加载

采用分页和延迟加载策略，避免一次性加载大量数据：

```javascript
// 分页配置
let paginationConfig = {
  currentPage: 1,
  pageSize: 20,
  totalPages: 1
};

// 只渲染当前页数据

const endIndex = Math.min(startIndex + paginationConfig.pageSize, videoData.length);
```

### 7.3 缩略图优化

优化缩略图生成和加载策略：

1. 缩略图生成使用视频30%位置的帧，避免黑屏或片头
2. 指定较小的缩略图尺寸(320x180)以降低存储需求
3. 使用本地文件系统存储缩略图，提高加载速度

```javascript
// 插件管理器设计
class PluginManager {
  constructor() {
    this.plugins = new Map();
  }
  
  registerPlugin(name, plugin) {
    if (this.validatePlugin(plugin)) {
      this.plugins.set(name, plugin);
      plugin.initialize();
    }
  }
  
  getPlugin(name) {
    return this.plugins.get(name);
  }
  
  validatePlugin(plugin) {
    // 验证插件接口实现
    return typeof plugin.initialize === 'function'

  }
}
```
